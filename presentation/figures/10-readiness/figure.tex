% Slide 10 — privacy.
%
% Titled to match the grounding slide ("What we do about hallucination"), so
% the deck answers its two hard questions in the same voice.
%
% Three separate claims, and all three are real:
%   the voice can stay on the machine  (local-ai/, built and round-trip tested)
%   the record already does            (local stores, no cloud database)
%   names never enter the record       (redaction at the publish boundary)
%
% No filenames anywhere. A store is described by what it holds — "the trial's
% medication log" — because that is the thing a judge can evaluate, where
% "conmed.db" is only evidence we have a filesystem.
