% Slide 02 — the list is stale and the visit is now.
%
% The slide used to be a visit timeline and a lot of white space. The visit
% strip alone never showed the thing that makes the list stale: the weeks
% behind it. So the top band is now that gap, carrying the four kinds of change
% that actually accumulate — a finished course, an over-the-counter purchase,
% a dose changed by someone else's doctor, a vaccination — and all of it funnels
% into the one dark box at the end of the visit.
%
% On the duration: the slide quotes AHRQ's 30-60 minutes per admission rather
% than picking a point inside it. A midpoint would have been a number we chose;
% the range is a number someone published. A time-and-motion study of 103
% observed reconciliations corroborates it — 46.2 minutes at internal-medicine
% admission, 92.2 in geriatrics. Both are hospital settings, not trial visits,
% and the slide says so in small type: the figure is defensible, the transplant
% between settings is the part a judge could reasonably question.
%
% Sizing the blocks by real minutes changed the argument for the better. At 50
% minutes med rec is not a box squeezed onto the end of the visit; it is the
% single largest thing in it, and it still only captures what they remember.
%
% The load-bearing claim is the last line, and that one is corroborated:
% conmed data is entered at the site visit, which makes the record a test of
% what the participant can recall since the last one.
